# ARR Bridge

How to construct an Annual Recurring Revenue Bridge (waterfall chart) in Plotly.

These files support the tutorial that can be found on Substack and Medium. Links are on my [web page](alanjones2.github.io).

There are two files:
- `arr-bridge.ipynb` is a Jupyter notebook that contains all of the code from the article.
- `app.py` is a Streamlit version with similar code
