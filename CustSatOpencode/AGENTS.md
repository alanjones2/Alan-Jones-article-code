# Customer Satisfaction Report

## Aims

To analyse the customer satisfaction for an online shoe shop and to produce a business report on the analysis. The data is given in the file data/shoes.md

### Specific aims

- to find the best and worst performing products 
- to show a graphic of the relative satisfaction of the products
- to analyse the reasons for the poor performance of products
- to produce a business report in HTML format


## Programming environment

- Any required programming should be in Python
- UV is installed.
- Before any programming is attempted a local virtual environment should be initialised using `uv init`
- Any Python libraries required should be installed with `uv add`

## Data

The data file data/shoes.md is the primary source of information. It is in Markdown format. It is structured as follows:

- The retailer name
- A list of products (shoes) and their descriptions
- Customer feedback: each product is named followed by a list of customer comments. The comments consist of a rating out of 5 and a textual comment.
